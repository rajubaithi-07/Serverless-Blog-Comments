# Serverless Blog Commenting System

## Project Overview
A cloud-based blog commenting system built using AWS serverless services.

## Technologies Used
- AWS AppSync
- Amazon DynamoDB
- Amazon S3
- GraphQL
- CloudFormation

## Features
- Add comments
- View comments
- Store comments in DynamoDB
- GraphQL API integration
- Serverless architecture

## Architecture
User → AppSync → DynamoDB

## AWS Services Used
1. AWS AppSync
2. Amazon DynamoDB
3. Amazon S3
